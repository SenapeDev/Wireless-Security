# Wireless  Security notes
This repository contains a collection of notes covering the fundamental principles of **wireless communications** and the **security aspects of modern wireless technologies**.

The material spans topics ranging from **signal processing** and **digital communication fundamentals** to the **protocols, architectures, and security mechanisms** behind major wireless systems, including:

- Global Navigation Satellite Systems (**GNSS**)
- Wi-Fi networks
- Bluetooth technologies
- Cellular communication systems

Whenever relevant, the notes also discuss **security threats**, including attacks, protocol vulnerabilities, design weaknesses, and the corresponding mitigation techniques associated with the technologies being analyzed.

The notes are available as a [website](https://senapedev.github.io/Wireless-Security/).

### Using the notes locally
If you would like to access or edit the Markdown files directly (for example, using **Obsidian**), simply clone this repository and open the `content` folder as your vault.
